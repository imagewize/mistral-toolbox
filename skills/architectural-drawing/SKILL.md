# Architectural Drawing

Draw a building the way an architect presents one: a clean elevation or section in ink lines, at a
true scale, with people and trees for size and one accent colour. The drawing is generated by a
small script that calls the kit in `scripts/arch.mjs`. You describe the building in metres; the
kit turns metres into SVG with one scale, draws every line at the right weight and checks the
result.

Never write SVG coordinates by hand. Hand-placed coordinates drift: roofs come out crooked, windows
overlap and a planter ends up as tall as a wall. Everything in this skill is in metres, so a door
is 2.4 m high wherever it is.

Why elevations and sections: they read instantly as architecture, they match a restrained page
style, and their scale can be checked. This skill does not draw perspective or isometric views.

## The look

- **Lines, not fills.** Paper-white fills only to hide what is behind. One optional tint.
- **A paper background.** Ink lines on a transparent SVG vanish on a dark page or preview, so the
  kit draws a paper-coloured background unless you pass `background: false`.
- **Line weights carry depth.** Heavier means nearer or cut. Use the kit's five weights only:

| Weight | SVG units | Use |
|--------|-----------|-----|
| `W.CUT` | 2.2 | Walls and slabs the section plane cuts (drawn as solid poche) |
| `W.PROFILE` | 1.4 | A building's outer silhouette, roof profiles, the ground line |
| `W.EDGE` | 0.9 | Openings, sills, quay edge, boats, trunks |
| `W.DETAIL` | 0.5 | Mullions, transoms, ground hatch, floor lines, tree crowns |
| `W.FAINT` | 0.35 | Brick coursing, glass reflections, water, trees behind |

- **Palette:** `ink`, `paper`, `tint`, `mid` and `accent`. The defaults are `#111111`, `#ffffff`,
  `#f3f3f3`, `#8a8a8a` and `#ff4f00`. Pass the page's own colours to `drawing({ palette })` so
  the drawing matches the site. For an inline SVG, a value may be a CSS variable with a fallback,
  such as `var(--wp--preset--color--contrast, #111111)`. An SVG used through `<img>` cannot read the
  page's CSS, so use hex values there.
- **One accent, used once or twice:** the entrance, one window or the boat. The kit warns at three.
- **Annotations are quiet:** one dimension line or one level mark at most, in the `mid` tone.

## Sizes in metres

Use real dimensions. The kit warns when a door, window, storey, figure or tree is outside these ranges.

| Element | Typical | Kit range |
|---------|---------|-----------|
| Storey, housing | 2.7–3.2 | 2.4–6.0 |
| Storey, warehouse or studio ground floor | 3.5–5.0 | 2.4–6.0 |
| Door, front | 1.0 x 2.3 | 0.8–4.5 wide, 1.9–4.8 high |
| Loading or garage door | 2.5–3.5 x 3.0–4.0 | as above |
| Window, housing | 1.0–1.6 x 1.4–2.2 | 0.4–4.0 wide, 0.5–5.0 high |
| Studio or shop glazing | 2.0–3.5 x 3.0–4.5 | as above |
| Sill above floor | 0.6–0.9 (0.3–0.6 for glazing) | |
| Person | 1.75 | 1.5–1.95 |
| Street tree | 8–14 (poplar 15–25) | 3–30 |
| Quay to water | 1.0–1.8 | |
| Barge | 30–80 long; draw 10–15 m of it for a vignette | |

## The kit

```js
import * as A from '/ABS/SKILL/DIR/scripts/arch.mjs';
const d = A.drawing({ width: 480, height: 300, extent: { x0, x1, top, bottom }, palette, scale, labels, displayWidth, prefix: 'xx-' });
```

`extent` is the part of the world to show, in metres: `x0..x1` along the facade, `top` above
ground and `bottom` below it (negative). The kit fits it into the drawing with a 14-unit margin
and reports the scale. Keep the extent tight: 1–3 m of context beyond the outermost tree or boat,
and 1–2 m above the highest point (2.5–3 m if there is a dimension line).

- **A set at one scale:** list every drawing's extent and compute the scale once with
  `A.sharedScale([ext1, ext2, ...], { width, height })`, then pass that `scale` to every
  `drawing()`. The largest building fills its drawing and the others keep their true size.
- **`displayWidth`:** the CSS width the drawing will be shown at, for example 330 for a card in a
  three-column grid. The kit then warns when people or labels get too small to read.
- **`labels: false`:** leaves out dimension and level text. Use it for drawings shown under about
  400 px wide, where 7-unit text shrinks below 6 px.

| Call | Draws |
|------|-------|
| `d.ground(x0, x1, { depth, hatch })` | Ground line with an earth hatch |
| `d.quay(x, x1, { level })` | A cut quay wall at `x` and water from `x` to `x1` at `level` |
| `d.mass(x0, x1, h, { base, fill: 'paper' \| 'tint' })` | A building block in elevation |
| `d.gableRoof(x0, x1, eave, ridge)` | A gable seen end-on |
| `d.stepGable(x0, x1, eave, ridge, { steps })` | A Dutch stepped gable (trapgevel) |
| `d.sawtoothRoof(x0, x1, eave, toothH, count)` | A sawtooth (shed) roof with glazing |
| `d.flatRoof(x0, x1, h, { parapet })` | A parapet with coping |
| `d.coursing(x0, x1, y0, y1, { course })` | Brick coursing, faint |
| `d.window(cx, sill, w, h, { mullion, transom, accent })` | One window |
| `d.windowRow(x0, x1, sill, head, count, opts)` | Evenly spaced windows; `accentIndex` picks one for the accent |
| `d.door(cx, w, h, { type: 'single' \| 'double' \| 'loading', base, accent })` | A door; `base` lifts it to an upper floor |
| `d.hoist(cx, y)` | A warehouse hoist beam and hook |
| `d.chimney(cx, base, { w, h })` | A chimney with a cap, standing on a roof or mass at height `base` |
| `d.floorLines(x0, x1, levels, { dashed })` | Floor levels; dashed on an elevation, solid in a section |
| `d.cut(x0, y0, x1, y1)`, `d.slab(x0, x1, level, { t })` | Section poche: cut walls and slabs |
| `d.stair(x0, y0, x1, y1, { steps })` | A stair in section |
| `d.figure(x, { h, pose, accent })` | A person, 1.75 m by default, with arms and legs. `pose`: `stand`, `walk`, `stand-left`, `walk-left`; vary them across a drawing |
| `d.tree(x, { h, type: 'round' \| 'poplar', layer: 'front' \| 'back' })` | A tree: solid trunk, scalloped crown, branches; `back` draws it faint and unfilled, behind buildings |
| `d.barge(x0, x1, level, { accent })` | A moored barge with a wheelhouse |
| `d.dimension(x0, x1, y, label, { from })` | A dimension line; `from` drops extension lines to that height (the ridge or eave). Labels use a decimal comma for Dutch sites |
| `d.levelMark(x, y, label)` | A level marker such as `+14,0` |
| `d.svg({ title, desc, background })` | The finished SVG; `title` is required and becomes the accessible name. `background` (default `true`) puts a paper-coloured rect behind the drawing, so it stays readable in dark previews and on dark pages |
| `A.write(file, svg)`, `A.printReport(d)` | Write the file; print the checks, exit 1 on errors |

The kit draws in layers, so call order matters only within a layer: back trees, ground and water,
building fills, building lines, details (coursing before openings, so openings cover it), front
(people and trees), annotations.

## Composition

- **One hero building**, 50–70% of the drawing width. Supporting masses are lower or set back.
- **The ground line runs the full width.** Water starts at a quay edge, never in mid-air.
- **At least one person** for scale near the hero's entrance. Two or three across the drawing is better.
- **Context on both sides:** a tree, a neighbouring block, a quay or a boat. Do not leave one half empty.
- **Leave sky.** Keep `top` 2–3 m above the highest ridge for the dimension line.
- **Spread openings in a rhythm** that follows the building's bays. Align windows on all floors.
- **Keep trees clear of the hero's corners.** A crown over a building corner hides the
  silhouette; the kit warns. Put the tree beside the building, or behind it with `layer: 'back'`.
- **A set of drawings** (for example six project cards) shares `width`, `height`, one scale from
  `sharedScale`, the palette and the annotation style, so the buildings compare at one size.
- **Cards:** a drawing in a card is shown small. Match the card's image frame to the drawing's
  aspect ratio (480x300 is 16:10) so no white bands appear, pass `displayWidth`, and use
  `labels: false` when the kit says labels are too small.

## Workflow

Run each command on its own. Do not chain with `&&`, `;` or `|`, and do not use shell variables.
Write absolute paths out in full.

1. **Brief.** For each drawing, write down the building type, width and height in metres, the
   storeys, the roof, the openings per floor, the context and which element gets the accent.
2. **Generator.** Copy `examples/pakhuis-quay.gen.mjs` into the project, for example to
   `scripts/<name>.gen.mjs`. Change its import to the absolute path of `scripts/arch.mjs`, and
   replace the layout table at the top with your building in metres.
3. **Run it:** `node scripts/<name>.gen.mjs images/<name>.svg`. It prints the scale and the checks.
   Fix every `ERROR`, and read every `WARN`: each one names the element and the size that is off.
4. **Check the file:** `node /ABS/SKILL/DIR/scripts/check.mjs images/<name>.svg` must print `PASS`.
5. **Render:** take a 2x screenshot with headless Chrome (on Linux `google-chrome` or `chromium`):
   ```
   "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --disable-gpu --hide-scrollbars --force-device-scale-factor=2 --window-size=480,300 --screenshot=/ABS/PROJECT/images/<name>.png "file:///ABS/PROJECT/images/<name>.svg"
   ```
   Use the drawing's own `width` and `height` in `--window-size`.
6. **Look.** If you can view images, check the render against the Verify list and fix what is off.
   If you cannot, say so in your reply, rely on the kit's checks, and name the PNG so a human can
   look.
7. **Use it.** Inline the SVG in the page, or save it as a file and reference it with `<img>`
   with an `alt` text. The kit's SVG is 10–30 KB, so inlining several is fine.

## Failure modes

- **Hand-written coordinates.** Any point not produced by the kit breaks the scale. Add a kit call
  or a kit option instead.
- **Desk-scale context.** Objects sized by eye next to a building (a planter as tall as a wall)
  destroy the scale. Every object here is in metres; keep to the ranges above.
- **No person.** Without a figure an elevation has no size. The kit warns.
- **Accent everywhere.** Three or more accent elements turn the drawing into a diagram. The kit warns.
- **Floating openings.** An opening outside every mass or roof is an error: it hangs in the air.
- **Overlapping openings.** Two windows or a window and a door on top of each other is an error.
- **Out of the frame.** An element outside the drawing is an error: widen `extent` or move it.
- **A clogged facade.** Coursing heavier than faint, or detail on every surface, reads as noise.
  Texture one main facade at most.
- **Mixed scales in a set.** Six cards at six scales make a villa look as big as a warehouse.
  Pass one `scale` from `sharedScale`.
- **Too small to read.** A loose extent or a large shared scale leaves the building small in its
  card: people become pins and labels vanish. Tighten the extents, then recompute `sharedScale`.
- **Something floating.** A mass or chimney that starts above the ground and does not stand on a
  mass or roof is an error.
- **Trees over corners.** The kit warns when a front tree's crown covers a mass corner.
- **Invalid SVG.** A repeated attribute makes the browser show an error page instead of the
  drawing. `check.mjs` catches it.

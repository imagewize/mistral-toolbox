# Product Marketing Context

Create a product marketing context document that other marketing skills reference.

## When to use

- Start of a new project, before using other marketing skills
- "Product context", "marketing context", "set up context"
- "Positioning", "who is my target audience", "describe my product"
- "ICP", "ideal customer profile"
- Avoid repeating foundational info across marketing tasks

## What to create

Write `.agents/product-marketing.md` in the project root with:

### 1. Product/service overview
- What it is, in one paragraph
- Core features/capabilities (3–5 bullets)
- What makes it different

### 2. Target audience / ICP
- Who is it for (roles, industries, company sizes)
- Their pain points (3–5 specific ones)
- What they care about (priorities, goals)
- Where they hang out (online communities, publications, events)

### 3. Positioning
- One-sentence value proposition
- Key messages (3–5)
- Proof points (results, testimonials, numbers)
- Competitive landscape (who else they consider, how you differ)

### 4. Voice and tone
- How the brand talks (conversational, technical, bold, etc.)
- Words to use / avoid

### 5. Goals
- Primary marketing goal (leads, signups, brand awareness)
- Key metrics
- Current campaigns or priorities

## Usage

Other skills (copywriting, cold-email, ai-seo, etc.) reference this file for product, audience, and positioning context so you don't repeat it every time.

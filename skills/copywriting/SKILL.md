# Copywriting

Write persuasive marketing copy for web pages.

## When to use

- "Write copy for [page]", "rewrite this page", "improve this copy"
- "Headline help", "CTA copy", "value proposition"
- "Tagline", "subheadline", "hero section copy"
- "Above the fold", "this copy is weak", "make this more compelling"
- Any website text that needs to persuade or convert

**Not for:** Email copy (use `cold-email`), editing existing prose (use `copy-editing`), microcopy in UI (use `ux-writing`).

## Framework: PAS + AIDA

For each section of a page, work through:

- **Attention** (headline): Stop the scroll. Use a specific number, a bold claim, or address a pain point directly.
- **Interest**: Expand on the problem or promise. One clear idea per paragraph.
- **Desire**: Show the transformation — what changes for the reader. Use proof (numbers, testimonials, first-hand results).
- **Action** (CTA): One clear next step. Button text should say what happens next ("Get my free audit", not "Submit").

## Voice guidelines

- Write like you talk — conversational, not corporate
- Second person ("you") over first person plural ("we") where possible
- Short sentences. One idea per sentence.
- Active voice: "We fixed the site in 2 days" not "The site was fixed in 2 days"
- Specific over vague: "cut load time by 60%" not "made it faster"

## Page-specific templates

### Hero section
- Headline: the one thing you do, for whom, with what result (max 10 words)
- Subheadline: one sentence expanding on how (max 20 words)
- CTA button: action-oriented, specific
- Social proof line: "Trusted by X companies" or a metric

### Feature section
- Feature name as heading (benefit, not feature name)
- 2–3 sentences on the outcome for the user
- Optional: small proof point or icon

### CTA section (end of page)
- Restate the core benefit in one line
- Remove friction: "No commitment", "Free", "5-minute setup"
- Button: clear action

## Quality checklist

- [ ] Headline passes the "so what?" test
- [ ] First paragraph hooks within 2 sentences
- [ ] One CTA per section, one primary CTA per page
- [ ] No jargon without explanation
- [ ] Benefits before features
- [ ] Read aloud — does it sound human?
